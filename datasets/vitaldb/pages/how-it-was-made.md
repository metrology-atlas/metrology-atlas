# How this atlas was made

The studies, code and pages were developed by Andrew J. Goodwin with substantial assistance from an AI assistant
(Claude, by Anthropic). The assistant wrote and ran analysis code, drafted text and figures, and proposed
interpretations; the author set the questions, reviewed the results and made the decisions.

Every number in the atlas comes from code that is published and can be rerun, every result states how it was
obtained, and the [open questions](open-questions.md) list what is not settled. Even so, mistakes may remain, in
the code, the numbers or the wording. Corrections are welcome: see [Contributing](contributing.md).
